Embedded control panel

Payment Ledger Console

A small browser UI for creating accounts, posting balanced journal entries, reversing transactions, and inspecting balances or statements against the live API.

/accounts Create and fetch ledger accounts.
/journal/transactions Post, inspect, and reverse journal transactions.
/accounts/:id/* Check balances and page through statements.

Accounts

Create or inspect a single account.

Transactions

Post balanced entries with any number of lines.
Amounts use BRL minor units. Total debits must equal total credits.

Lookup And Reverse

Inspect a transaction by ID or reference, then reverse it.
